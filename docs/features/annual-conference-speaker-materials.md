# Annual Conference speaker materials

Participation shows each accepted speaker's confirmation, headshot and social-handle status before opening their details. The headshot status distinguishes an uploaded original, an external link and a missing headshot; an unused badge photo does not count as a submitted headshot. Empty social handles are shown as missing. The drawer leads with these answers and any technical or accessibility needs, then offers the optional badge and session materials in a disclosure. A blank support answer does not mean support is required or refused.

For 2026 Participation also shows the number and size of current speaker badge photos, alongside total shared photo storage (including headshots, attendee badges and retained uploads). The totals refresh every minute while Participation is visible. They are measurements, not limits. Delivery opens the decision email status, recipient, attempt count, timestamps, and available recovery actions.

Selected speakers can upload optional PDF, PPT, and PPTX files in their private workspace. Uploading a file is separate from saving the optional slides or resource URL and session logistics. The workspace permits five files per accepted session, each at most 5 MiB. Selecting a file stages it; **Upload file** saves it independently of logistics and badge edits. Leaving with a staged file or unsaved changes triggers a warning. Speakers can clear a staged selection or confirm removal of an uploaded file to free one of the five slots. Organizers can download the remaining files from the proposal drawer.

The form shows file type, size and remaining capacity before upload, then reports transfer progress and waits for the server to confirm the save. Badge photos accept JPEG, PNG, WebP or AVIF up to 5 MiB. Each badge has one active photo in the private Supabase Storage bucket `annual-conference-social-cards`. The speaker can replace it or confirm removal through the private workspace. The badge preview shows current edits before saving or downloading; it opens as a dialog on desktop and a bottom drawer on phones.

The private workspace puts the publicity headshot and social handles first. Speakers can upload a JPEG, PNG, WebP or AVIF up to 5 MiB, save an external HTTPS link, or reuse the saved original badge photo. These are alternative headshot sources. Headshot changes save independently; social handles, participation confirmation and support answers use **Save details**. An unfinished headshot link and unsaved form or badge edits participate in the leave-page warning.

Reusing a badge photo creates a private copy of the original image for the organizers, not a rendered badge. Replacing or removing the badge photo cannot remove that headshot. Badge customization is optional and collapsed initially; collapsing the editor preserves unfinished name and crop edits. Session materials remain available under a later, optional section. The 2026 publicity request asks for the headshot and social handles by 12 November; the existing session logistics due date still does not revoke access.

Authorized speaker viewers can open a submitted external link or download the original uploaded headshot in the proposal drawer. External URLs are validated but never fetched or automatically embedded. Headshots use the existing private `annual-conference-social-cards` bucket and are not automatically published; public programme photos and public badge sharing retain their own controls. Revision-checked source changes reject stale saves rather than overwrite another browser's selection. Replaced or cleared headshot objects are retained for recovery, like superseded badge uploads, and remain included in the shared-bucket storage total.

Each request checks the existing workspace token, selected proposal and session, and revocation. The logistics deadline is a due date and does not end access. Organizers with `speakers.manage` can revoke a private workspace link without issuing a replacement; revocation also blocks speaker file and badge access. Organizer downloads require an authenticated organizer with `speakers.view` for the conference year and are scoped to the selected session. Files live in a private Supabase Storage bucket and downloads use attachment disposition. Type, extension, size, and file signatures are checked; PPTX files also require a structurally valid ZIP directory with presentation entries. These checks are not malware scanning.

The local migration `20261101100000_annual_conference_speaker_materials.sql` creates the private bucket, metadata table, and serialized five-file limit. Its migration verification contract checks the bucket configuration, access restrictions, table, and quota trigger. Deployment requires applying and verifying this forward migration in the target environment through the established migration delivery process; it is not applied by this implementation.

The local migration `20261103130000_speaker_private_details.sql` adds the three private detail fields to conference sessions. Its verification contract checks the columns. Apply and verify it through the established migration delivery process before deploying code that reads or writes these fields; it has not been applied by this implementation.

The Participation storage readout requires the forward migration `20261103140000_speaker_badge_storage_usage.sql`. Its aggregate is callable only by the service role; the organizer endpoint requires `speakers.view`. If the query is unavailable, the readout offers a retry without blocking participation management.

The headshot workspace requires `20261105130000_speaker_headshot_workspace.sql`. It adds a private photo reference and revision to conference sessions and prevents a saved upload and external link from being selected simultaneously. Existing links remain intact. Apply and verify this additive migration through the migration delivery process before deploying this feature; implementation and browser previews do not apply it.

Organizers can find the badge preview, headshot, and uploaded files together in the speaker drawer’s Assets section. The Assets section is visible alongside Logistics and Speaker workspace in the Participation drawer.
