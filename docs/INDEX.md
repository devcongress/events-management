## Quick Summary

**DevCongress Events Management** — Vue 3 + Vite organizer console and event-data backbone for DevCongress, served through a single Bun/Hono app server. Public community pages belong on `devcongress.org`; this app owns private event operations, the read-only public integration API, and Supabase-backed organizer auth with app-owned HTTP-only sessions. Prototype data still uses JSON flat files in several areas.

**Stack:** Vue 3 · Vite 6 · TypeScript 5 · Bun · Hono · TanStack Query · Tailwind CSS 3 · pnpm

## Key Facts (Instant Orientation)

- **App shell:** `src/` Vue SPA with Vue Router; `server/` Hono API and Bun production server
- **Legacy reference:** previous Next.js implementation remains in `app/`, `components/`, and `hooks/` during migration
- **Admin auth** — every organizer route uses Supabase Google OAuth plus app-owned HTTP-only sessions; missing configuration fails closed with no shared-password fallback
- **Quiz real-time** — polling every 1500ms; clients call explicit `POST /api/quiz/state/advance` before read-only state fetches
- **Scoring** — `base × (0.5 + 0.5 × speed)` + streak bonus (2→+100 … 5+→+500)
- **Mock DB** — `lib/mock-db/index.ts`: `readData<T>` / `writeData<T>` over `data/*.json`, with corrupt JSON failing loudly and writes using temp-file rename
- **Design tokens** — `dc-*` Tailwind classes + `lib/design-system.ts` for JS-side usage
- **Seed DB** — `pnpm seed`
