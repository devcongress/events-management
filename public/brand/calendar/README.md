# Calendar provider marks

These locally hosted 64px PNGs are rasterized reference marks used only beside the text calendar choices in the event-blast email. They are decorative (`alt=""`); each action remains fully identifiable when remote images are blocked.

Source references, verified and rasterized on 2026-09-29:

- Google Calendar: <https://www.gstatic.com/images/branding/productlogos/calendar_2026/v2/web/192px.svg>
- Apple Calendar: <https://www.apple.com/favicon.ico>
- Microsoft Outlook: <https://res.public.onecdn.static.microsoft/assets/mail/pwa/v4/pngs/apple-touch-icon.png>

The email serves these provider icons only from local PNGs at `https://em.devcongress.org/brand/calendar/`; they do not rely on third-party hosts at send or open time.
