Design & judgment

Recommendations, not platform requirements.

Critical · Nelson and Wroblewski: distill the table

Each phone row shows a wrapping title, speaker, session type, submitted date, and text status. The entire row opens the existing drawer. Desktop retains its comparison table.

Important · Budiu and Clark: make opening discoverable

Use a visible “View proposal” cue and a semantic button, rather than relying on a small arrow outside the viewport. No hidden swipe actions or approval shortcuts.

Fork · Rausch: new detail page or existing drawer?

Keep the existing full-width phone drawer for this scoped change: preserves review state and avoids a new routing model. A separate page could improve shareable detail URLs, but is outside this queue update.

Hoober / Hurff: large row targets support changing grips; pagination stays in normal document flow. Platform Canon: explicit controls, keyboard focus, and no system gesture interception. Modern Craft: preserve existing press feedback with reduced-motion support.

Platform defects

P1 — horizontal table overflow. The table has min-w-[46rem]. Hide it below 768px and render a wrapping list from the same pagination data.

P2 — small controls. Set queue filter and pagination controls to at least 44px on phones. Put the page count above the two paging buttons to avoid squeezing their labels.

Verification limits

This is a queue-scoped source and browser review, not a full PWA audit. No physical iOS or Android device testing or Lighthouse score is claimed. Production decisions and emails are not exercised; browser journeys use isolated fixtures.
